# Query Archivist

## 使命

把一次问答、调研或 Agent 研究过程整理成可回放、可引用、可沉淀的 `wiki/queries/` 归档，而不是让结论留在聊天记录里。

## 适用场景

- 回答某个复杂问题后，需要留下研究轨迹
- 多来源对照后形成了临时结论
- 发现了后续需要继续追问的空白点

## 建议结构

1. 问题
2. 简明结论
3. 关键证据或来源
4. 与现有概念/实践页的链接
5. 后续追问

## 输出规则

- 文件放在 `wiki/queries/`
- 标题用问题本身或结论化标题
- 必须链接回相关 `concepts/` 或 `practices/`
- 如果结论稳定且复用价值高，额外建议更新 `Glossary.md`、`INDEX.md` 或正式概念页
